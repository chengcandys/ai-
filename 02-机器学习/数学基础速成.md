# 深入专题 · AI 数学基础速成（线性代数 / 概率 / 微积分）

> 不必学完数学再学 AI。本篇只收"理解 AI 绕不开的最小数学集"，每个概念都挂到具体 AI 场景。

## 1. 线性代数：AI 的"数据语言"

### 1.1 向量与矩阵

- **向量**：一个样本/一段语义的数值表示。Embedding 就是向量——"猫"和"狗"的向量距离近
- **矩阵 × 向量**：对向量做**线性变换**（旋转/缩放/投影）。神经网络的每一层 `Wx` 就是一次空间变换
- 直觉：深度网络 = 一连串空间变换，把"纠缠的数据"逐步变换到"线性可分"的空间

### 1.2 必须掌握的 5 个运算

| 运算 | 公式/形状 | AI 场景 |
|------|-----------|---------|
| 点积 | $a \cdot b = \sum_i a_i b_i$ | 注意力分数 Q·K、余弦相似度分子 |
| 矩阵乘法 | $[m,k] \times [k,n] = [m,n]$ | 神经网络层计算（占 99% 算力） |
| 转置 | $A^T$ | 反向传播梯度维度对齐 |
| 范数 | $\|x\|_2 = \sqrt{\sum x_i^2}$ | 向量归一化、L2 正则、梯度裁剪 |
| 特征值分解 | $Av = \lambda v$ | PCA 主成分方向 |

### 1.3 余弦相似度（RAG 的核心）

$$\cos(\theta) = \frac{a \cdot b}{\|a\| \, \|b\|}$$

- 只看方向不看长度 → 长文本和短文本可公平比较
- 值域 [-1, 1]，语义越像越接近 1

### 1.4 秩（Rank）与 LoRA

- 秩 = 矩阵"独立信息量"的度量
- LoRA 假设：微调时权重的变化量 ΔW 是**低秩**的（任务增量信息远小于全量参数）→ 用两个小矩阵 BA（秩 r）近似，r=8~64 即可

## 2. 概率论：AI 的"不确定性语言"

### 2.1 条件概率与贝叶斯

$$P(A|B) = \frac{P(B|A)\,P(A)}{P(B)}$$

- LLM 的本质就是建模条件概率 $P(x_{t} \mid x_1, \dots, x_{t-1})$：给定上文，下一个 token 的概率分布

### 2.2 期望、方差

- 期望 = 加权平均；方差 = 波动程度
- 偏差-方差权衡（Bias-Variance Tradeoff）就是期望与方差在模型误差上的体现

### 2.3 常见分布

| 分布 | 场景 |
|------|------|
| 正态分布 $N(\mu, \sigma^2)$ | 权重初始化、VAE、扩散模型噪声 |
| 伯努利/类别分布 | 分类问题建模 |
| softmax 分布 | LLM 输出 token 概率 |

### 2.4 交叉熵与 KL 散度（重点）

- **信息量**：$I(x) = -\log P(x)$，越不可能的事信息量越大
- **熵**：$H(P) = -\sum P \log P$，分布的不确定性
- **交叉熵**：$H(P, Q) = -\sum P \log Q$ —— 用分布 Q 编码真实分布 P 的代价 → **分类/语言模型的损失函数**
- **KL 散度**：$D_{KL}(P \| Q) = \sum P \log \frac{P}{Q}$ —— 两个分布的差异（不对称！）→ RLHF 中约束策略别偏离太远、VAE 的正则项

为什么分类用交叉熵而不是 MSE？—— 交叉熵在 softmax 配合下梯度不含 sigmoid 饱和项，错得越狠梯度越大，学得快；MSE 在输出极端时梯度趋近于零。

## 3. 微积分：AI 的"学习引擎"

### 3.1 导数与梯度

- 导数：函数在某点的变化率；梯度 $\nabla f$：多元函数各方向偏导组成的向量，指向**上升最快方向**
- 梯度下降：$\theta \leftarrow \theta - \eta \nabla_\theta L$ —— 反着梯度走，Loss 降得最快

### 3.2 链式法则（反向传播的数学基础）

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial x}$$

- 深层网络 = 函数套函数 → 总梯度 = 各层局部梯度的**连乘**
- 这也解释了梯度消失：很多 <1 的数连乘 → 趋近 0

### 3.3 一个数值例子（手算一遍终身不忘）

$f(x) = x^2$，初始 $x = 2$，学习率 $\eta = 0.1$：

```
第1步：f'(2) = 4  → x = 2 - 0.1×4 = 1.6
第2步：f'(1.6) = 3.2 → x = 1.6 - 0.32 = 1.28
...x 逐步逼近最优解 0
```

学习率 0.5 时：x = 2 → 0 → 0（震荡）；学习率 1.5 时直接发散 —— 这就是"学习率太大学过头"的直观含义。

## 4. 信息论速览（选学，LLM 进阶）

- **困惑度 PPL** = $2^{H(P,Q)}$：语言模型的标准指标，直观含义"模型平均在几个候选词之间犹豫"，越低越好
- 交叉熵损失与 PPL 的关系：$\text{PPL} = e^{\text{Loss}}$ → Loss 0.69 对应 PPL ≈ 2（在两个词间犹豫）

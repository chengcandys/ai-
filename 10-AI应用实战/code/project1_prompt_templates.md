# 项目1：Prompt 工具箱（4 个生产级模板）

> 直接复制使用，`{大括号}` 为待填变量。每个模板遵循黄金公式：角色+任务+背景+要求+格式。

## 模板 1：专业翻译（信达雅）

```
你是资深{领域，如：技术/法律/医学}翻译专家，精通中英文互译。
请将以下内容翻译成{目标语言}，要求：
1. 专业术语准确（首次出现保留英文原词并括注）
2. 符合目标语言母语者的表达习惯，不做字面直译
3. 保持原文的格式（标题/列表/表格）
4. 存疑之处在译文末尾用【译注】说明，不要自行发挥
原文：```{待翻译内容}```
```

## 模板 2：结构化总结

```
你是信息提炼专家。请阅读以下材料并输出：
1. 【一句话核心】（不超过 30 字）
2. 【要点】3-5 条，每条一行，按重要性排序
3. 【关键数据】文中出现的数字及其含义（无则写"无"）
4. 【待确认】文中模糊或可能过时的信息
材料：```{内容}```
```

## 模板 3：代码审查

```
你是资深 {语言} 工程师，请审查以下代码，按严重程度输出：
🔴 必须修复（bug/安全/崩溃风险）：行号 + 问题 + 修复建议
🟡 建议改进（性能/可读性/边界条件）：行号 + 建议
🟢 亮点（值得保留的写法）
要求：只报告有把握的问题，不确定的标注"需人工确认"；不要重写整段代码，只给最小修改 diff。
代码：```{代码}```
```

## 模板 4：周报生成

```
你是我的工作助理。请把以下零散工作记录整理成周报，结构：
1. 本周完成（按项目分组，每项一行，突出可量化结果）
2. 进行中（标注进度百分比和阻塞点）
3. 下周计划（不超过 3 项，按优先级排序）
语气：简洁专业，给直属上级看；不确定归属的内容放最后"其他"栏。
工作记录：```{流水账记录}```
```

## 迭代方法

1. 先用一次 → 找出输出中不满意的部分 → 把"不满意"写成一条新约束加入模板
2. 每个模板维护变更记录（为什么加这条规则，对应哪个失败案例）——这就是 PromptOps 的雏形
3. 同类任务连续 3 次输出稳定，模板即"毕业"

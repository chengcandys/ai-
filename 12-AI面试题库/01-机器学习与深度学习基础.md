# 01 · 机器学习与深度学习基础（25 题）

## 机器学习基础

### Q1. 过拟合和欠拟合是什么？如何解决？
- **欠拟合**：模型太简单，训练集都学不好 → 增加模型复杂度、增加特征、减少正则化、训练更久
- **过拟合**：死记训练集，泛化差 → 更多数据、正则化（L1/L2）、Dropout、早停（Early Stopping）、数据增强、降低模型复杂度、交叉验证

### Q2. L1 和 L2 正则化的区别？
- L1（Lasso）：加权重绝对值，产生**稀疏解**（部分权重变 0）→ 可做特征选择
- L2（Ridge）：加权重平方，权重整体变小但不为 0 → 更平滑稳定
- 几何解释：L1 约束区域是菱形，顶点易与损失等高线相切 → 稀疏

### Q3. 偏差（Bias）与方差（Variance）权衡？
- 偏差高 = 欠拟合（模型太简单）；方差高 = 过拟合（对数据扰动敏感）
- 总误差 ≈ 偏差² + 方差 + 不可约噪声；调模型复杂度就是在两者之间找平衡

### Q4. 常用的分类评估指标？什么场景用什么？
- **准确率 Accuracy**：类别均衡时用
- **精确率 Precision**：预测为正的样本中有多少真为正 → 误报代价高时用（垃圾邮件）
- **召回率 Recall**：真实正样本中找回多少 → 漏报代价高时用（疾病筛查、风控）
- **F1**：P 与 R 的调和平均
- **AUC-ROC**：排序能力，对类别不平衡不敏感
- **混淆矩阵**：所有指标的基础

### Q5. 类别不平衡怎么处理？
- 数据层：过采样（SMOTE）、欠采样、类别权重
- 算法层：代价敏感学习、阈值调整（不按 0.5 一刀切）
- 评估层：用 PR-AUC / F1 而非准确率

### Q6. 交叉验证怎么做？为什么？
- K 折交叉验证：数据分 K 份，轮流用 1 份验证、K-1 份训练，取平均
- 目的：更稳健地估计泛化性能、辅助调参；小数据集尤其重要
- 注意：时序数据不能用随机 K 折，要用时间滑窗

### Q7. 特征工程有哪些常用手段？
- 数值特征：归一化/标准化、分桶、log 变换、缺失值填充
- 类别特征：One-Hot、Label Encoding、Target Encoding、Embedding
- 组合特征：交叉特征、多项式特征；时序特征：滑窗统计
- 特征选择：过滤式（相关系数）、包裹式（递归消除 RFE）、嵌入式（L1、树模型重要性）

### Q8. 决策树、随机森林、GBDT/XGBoost 的区别与联系？
- 决策树：单棵树，易过拟合
- 随机森林：多棵树 **Bagging**（并行独立采样训练）+ 随机特征子集 → 降方差
- GBDT/XGBoost：**Boosting**（串行，每棵新树拟合前面的残差/梯度）→ 降偏差
- XGBoost 工程优化：二阶泰勒展开、正则项、列采样、缺失值自动处理

### Q9. K-Means 的原理与局限？
- 原理：随机选 K 个中心 → 分配样本到最近中心 → 更新中心为簇均值 → 迭代收敛
- 局限：需预设 K、对初始点敏感（K-Means++ 缓解）、只适合凸形簇、对异常值敏感
- 评估：肘部法则、轮廓系数

### Q10. PCA 的原理？
- 找数据方差最大的正交方向（主成分），投影降维
- 数学本质：协方差矩阵特征值分解 / SVD
- 用途：降维加速、去噪、可视化；前提：特征间有相关性

## 深度学习基础

### Q11. 反向传播的本质是什么？
- 链式求导法则：从损失函数出发，逐层把梯度传回每个参数
- 前向算输出和 Loss → 反向算梯度 → 优化器更新参数

### Q12. 梯度消失和梯度爆炸？如何解决？
- 消失：深层网络连乘小梯度 → 前层学不动；爆炸：梯度连乘过大 → 训练发散
- 对策：合适激活函数（ReLU 替代 Sigmoid）、残差连接（ResNet）、批归一化 BN/LN、梯度裁剪（爆炸）、合适的初始化（Xavier/He）

### Q13. 常用激活函数对比？
| 函数 | 特点 | 问题 |
|------|------|------|
| Sigmoid | 输出 0~1 | 两端饱和梯度消失、非零中心 |
| Tanh | 零中心 | 仍饱和 |
| **ReLU** | 计算快、缓解消失 | 神经元死亡（Dead ReLU） |
| Leaky ReLU | 负半轴小斜率 | 解决死亡问题 |
| GELU/SiLU | 平滑版 ReLU | Transformer 主流 |

### Q14. 常见优化器对比（SGD/Momentum/Adam）？
- SGD：简单，易陷局部最优/震荡
- +Momentum：积累历史梯度方向，加速收敛、减少震荡
- Adam：一阶动量 + 二阶自适应学习率，收敛快、默认首选
- AdamW：权重衰减与梯度解耦，大模型训练主流

### Q15. Batch Normalization 和 Layer Normalization 区别？
- BN：对**同一特征跨 batch** 归一化，依赖 batch 大小 → CNN 常用
- LN：对**同一样本跨特征** 归一化，与 batch 无关 → Transformer/NLP 标配
- 作用：稳定分布、加速收敛、允许更大学习率、轻微正则效果

### Q16. Dropout 原理？训练和推理时行为？
- 训练时随机以概率 p 丢弃神经元 → 等效训练指数级子网络集成，防过拟合
- 推理时全部保留，权重乘 (1-p) 或训练时做 inverted scaling
- 大模型时代使用变少（数据量大 + LN 已足够稳定）

### Q17. 学习率如何设置？有哪些调度策略？
- 太大会震荡发散，太小收敛慢
- 策略：Step 衰减、余弦退火（Cosine）、线性 Warmup + 衰减（LLM 训练标配）
- Warmup 作用：训练初期参数随机，小学习率稳定起步

### Q18. 损失函数怎么选？
- 分类：交叉熵 CrossEntropy（二分类用 BCE）
- 回归：MSE（对异常值敏感）、MAE（鲁棒）、Huber（折中）
- 生成：对比学习 InfoNCE、扩散模型噪声预测损失

### Q19. CNN 的核心设计思想？
- **局部连接**：卷积核只看局部区域（符合图像局部相关性）
- **参数共享**：同一卷积核扫全图 → 参数量骤降
- **池化/步长**：逐级扩大感受野、降低分辨率
- 层级特征：低层边缘 → 中层纹理 → 高层语义部件

### Q20. 感受野是什么？如何扩大？
- 某层神经元"看到"的原始输入区域大小
- 扩大方式：加深网络、池化、大步长、空洞卷积（Dilated Conv，不丢分辨率）

### Q21. RNN/LSTM/GRU 的演进逻辑？
- RNN：处理序列但长序列梯度消失
- LSTM：引入输入门、遗忘门、输出门 + 细胞状态 → 选择性记忆，缓解长依赖
- GRU：合并为更新门+重置门，参数更少、效果相当
- 最终被 Transformer 取代的原因：无法并行、长距离仍衰减

### Q22. 深度学习 vs 树模型，各自适用场景？
- 深度学习：图像/文本/语音等非结构化大数据、端到端特征学习
- 树模型（XGBoost）：结构化表格数据、中小数据量、要求可解释性、训练快
- 面试加分点：能说出"数据模态和规模决定选型"

### Q23. ResNet 残差连接为什么有效？
- 学残差 F(x) = H(x) - x 比直接学 H(x) 容易；恒等映射保底
- 梯度可通过捷径直接回传，缓解深层网络梯度消失 → 可训百层以上

### Q24. 数据增强有哪些手段？
- 图像：翻转、裁剪、旋转、色彩抖动、Mixup、CutMix
- 文本：同义替换、回译、随机删除/交换
- 作用：变相扩数据、提升泛化、防过拟合

### Q25. 模型不收敛，你的排查顺序？
1. 检查数据和标签（脏数据是头号杀手）
2. 用小数据过拟合测试：能否把 loss 打到接近 0（验证代码正确性）
3. 调学习率（最常见原因）、检查梯度是否消失/爆炸（打日志）
4. 检查归一化、初始化、损失函数实现
5. 简化模型逐步加回复杂度定位问题

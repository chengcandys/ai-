# 02 · Transformer 与 LLM 原理（25 题）

## 注意力机制

### Q1. LLM 的本质是什么？为什么 Transformer 能成为核心架构？
- **本质**：海量文本自监督预训练，学习语言统计规律、语义逻辑与世界知识，通过自回归"预测下一个 token"完成各类任务；核心能力来自**规模带来的涌现**（上下文学习、推理、指令遵循）
- **Transformer 胜出的三大原因**：
  1. 长距离依赖：任意两 token 直接算关联，解决 RNN 梯度消失
  2. 并行计算：序列并行处理，适配 GPU，支撑千亿参数训练
  3. 架构扩展性：多头注意力 + 残差 + LN，可扩展到 BERT/GPT/多模态

### Q2. 自注意力的计算公式与步骤？
- 公式：`Attention(Q,K,V) = softmax(QK^T / √d_k) V`
- 5 步：① 线性层生成 Q/K/V → ② Q·K 点积算关联度 → ③ 除以 √d_k 缩放 → ④ 加掩码（解码器用因果掩码防"偷看未来"）→ ⑤ softmax 后与 V 加权求和
- 直觉：Query 是"我要找什么"，Key 是"我是什么"，Value 是"我携带的信息"

### Q3. 为什么要除以 √d_k 缩放？
- d_k 大时点积方差变大 → softmax 进入饱和区 → 梯度趋近 0（梯度消失）
- 除以 √d_k 把点积方差拉回 1 附近，保持 softmax 在敏感区间

### Q4. 多头注意力的价值？
1. 不同头捕捉不同维度语义（句法、语义、长依赖、局部上下文）
2. 高维拆成低维头并行计算，复杂度可控
3. 提升泛化，避免单头表征偏差
- 头数不是越多越好，过多会稀释每个头的表征能力

### Q5. MHA / MQA / GQA 的区别？
- **MHA**（标准多头）：每个头独立 Q/K/V → 表达强，但 KV Cache 大
- **MQA**：所有头共享一组 K/V → Cache 最小、解码快，质量略降
- **GQA**：头分组共享 K/V → 质量与效率折中，Llama2/3、Qwen 主流选择
- 面试要点：优化的都是**推理期 KV Cache 显存与带宽**

### Q6. 自注意力的时间/空间复杂度？长文本瓶颈在哪？
- 复杂度 O(n²·d)：n 为序列长度 → 长文本时 QK^T 矩阵平方级增长
- 优化方向：稀疏注意力（Longformer）、线性注意力、FlashAttention（IO 感知，不降复杂度但省显存提速）、滑动窗口注意力（SWA）

### Q7. FlashAttention 的原理？
- 不改注意力数学结果，而是**减少 GPU 显存读写（IO-aware）**
- 核心：分块（Tiling）计算 + 在线 softmax，避免把 N×N 注意力矩阵写入 HBM
- 效果：显存从 O(n²) 降到 O(n)，训练/推理显著提速，长上下文成为可能

## 位置编码

### Q8. 为什么需要位置编码？
- 自注意力本身**置换不变**（对 token 顺序不敏感），必须显式注入位置信息让模型感知语序

### Q9. 绝对位置编码 vs 相对位置编码？
- 绝对：每个位置一个固定/可学习向量（原始 Transformer 的 sin-cos）
- 相对：建模 token 间相对距离 → 泛化和外推更好，现代 LLM 主流

### Q10. RoPE（旋转位置编码）原理与优势？
- 原理：把 Q/K 按位置在复数空间旋转，使内积天然包含相对位置信息（相对位置越近点积越大）
- 优势：① 天然相对位置特性；② 长文本外推性好（可配合线性插值、NTK-aware 插值扩窗）
- 采用者：LLaMA、Qwen、DeepSeek 等几乎全部主流开源模型

### Q11. ALiBi 的原理与优势？
- 原理：不改 embedding，在 softmax 前给注意力分数加与距离正相关的线性偏置（近处加分、远处惩罚）
- 优势：外推性极强，无需微调即可处理远超训练长度的序列；无额外参数

### Q12. RoPE 长文本外推有哪些方案？
- 位置插值（PI）：把长位置压缩到训练范围内
- NTK-aware 插值：高频少缩、低频多缩，效果更好
- YaRN：分段插值 + 温度调整，目前主流扩窗方案之一
- 追问点：外推本质是让模型"没见过"的旋转角度落回已学分布

## 架构与组件

### Q13. Encoder / Decoder / Encoder-Decoder 三种架构对比？为什么主流用 Decoder-only？
- Encoder（BERT）：双向注意力，适合理解任务，不适合自回归生成
- Encoder-Decoder（T5）：理解与生成分离，结构重
- **Decoder-only（GPT）**：因果注意力完美适配"预测下一个 token"，可用上下文学习统一所有任务；工程简单、易 Scaling → 通用大模型的事实标准

### Q14. Pre-Norm 和 Post-Norm 区别？
- Post-Norm（原始 Transformer）：残差后归一化，深网训练不稳定
- **Pre-Norm（现代 LLM）**：先归一化再进子层 → 梯度通路更通畅，可稳定训练百层网络，大模型标配
- RMSNorm：省去均值中心化，计算更省，Llama 系列采用

### Q15. FFN 层的作用？SwiGLU 为什么流行？
- FFN 提供非线性变换与知识存储（有研究认为 FFN 类似键值记忆库）
- 结构：升维 → 激活 → 降维，参数量约占模型 2/3
- SwiGLU：门控激活（x·sigmoid 变体），相比 GELU 收敛更快效果更好 → Llama/Qwen 标配

### Q16. Tokenizer 做什么？BPE 原理？
- 把文本切成 token 序列；词表大小影响表达效率与成本
- BPE：从字符开始，迭代合并最高频的相邻 token 对 → 平衡词表大小与未登录词问题
- 追问：为什么 LLM 算数差？数字被切碎成 token，无法按位对齐计算

### Q17. 什么是涌现能力（Emergent Ability）？
- 模型规模跨过阈值后突然出现的未显式训练能力（少样本学习、思维链推理等）
- 面试加分：也有研究认为部分是评估指标非线性造成的"假象"，体现批判性思考

### Q18. Scaling Law 是什么？
- 模型性能（Loss）与参数量、数据量、算力呈幂律关系，可预测
- Chinchilla 结论：参数与数据应**同步扩**（约 1:20 token/参数比），过去模型普遍"大参数小数据"欠训练
- 意义：指导"给定算力预算，参数和数据怎么分配"

### Q19. MoE（混合专家）原理与优劣？
- 原理：FFN 换成 N 个专家，Router 每 token 只激活 Top-K 个（如 8 选 2）
- 优势：总参数大、激活参数小 → 同等推理成本下更强（DeepSeek-V3、Mixtral）
- 难点：训练不稳定、负载均衡（需 auxiliary loss）、通信开销大

### Q20. KV Cache 是什么？为什么推理必须用它？
- 自回归生成时缓存之前所有 token 的 K/V，避免每步重算 → 复杂度从 O(n²) 降到 O(n)/步
- 代价：显存占用 = 层数 × 头数 × 维度 × 序列长 × 2(K,V)，长文本+大 batch 时成为瓶颈
- 优化：GQA/MQA、PagedAttention（vLLM）、KV Cache 量化/压缩、滑动窗口

## 推理与输出控制

### Q21. 常见解码策略对比？
- **Greedy**：每步取最大概率 → 稳定但单调重复
- **Beam Search**：保留 top-B 候选 → 翻译类任务好，开放式生成显呆板
- **Temperature 采样**：调节分布平滑度，0 接近 greedy，大则发散
- **Top-p（Nucleus）**：只在累计概率达 p 的最小集合内采样 → 质量与多样性兼顾，主流
- **Top-k**：只在概率最高的 k 个中采样

### Q22. Temperature / Top-p 怎么配合调？
- 事实问答/代码：T=0~0.3，求稳
- 日常对话：T=0.7 左右 + Top-p 0.9
- 创意写作：T=0.9~1.2
- 原则：一次优先调一个参数，Top-p 控制"候选池"，T 控制"池内分布锐度"

### Q23. 什么是幻觉（Hallucination）？成因与缓解？
- 成因：训练数据噪声/缺失、自回归误差累积、过度自信的概率生成、知识边界不清
- 缓解：RAG 引入真实来源、让模型引用出处、提示"不知道就说不知道"、后处理事实校验、微调对齐、降低温度
- 面试加分：区分**事实性幻觉**与**忠实性幻觉**（与输入矛盾）

### Q24. 思维链（CoT）为什么有效？推理模型（R1/o 系列）怎么做到的？
- CoT：把复杂问题分解为中间步骤 → 分配更多计算量到推理过程，减少一步到位的错误
- 推理模型：用**强化学习**（如 GRPO）奖励"先长链思考再作答"的行为，涌现出自我验证、反思回溯能力
- Test-time Scaling：推理时花更多 token 换更高准确率，是 Scaling 新维度

### Q25. 上下文窗口如何扩展？成本是什么？
- 手段：RoPE 外推（NTK/YaRN）、高效注意力（稀疏/滑窗）、位置编码改进、长文本继续预训练
- 成本：注意力 O(n²) 计算、KV Cache 线性增长、"大海捞针"（Lost in the Middle，模型对中段信息利用差）
- 面试常考："长上下文会不会取代 RAG？"——见 [04-RAG](./04-RAG与知识库.md) Q24

# 07 · 项目与开放题（15+ 题）

> 大厂面试中项目深挖占 50% 以上时间。本篇帮你准备"讲得出、扛得住追问"的项目故事线。

## 一、项目深挖通用框架

### Q1. 介绍一个你做过的最有挑战的 AI 项目（必考）
**STAR + 技术深度结构**：
1. **背景**：业务问题是什么，为什么值得做（量化痛点）
2. **方案**：为什么选这个技术路线（对比过哪些备选）
3. **难点**：最硬的 1~2 个问题 + 解决过程
4. **结果**：量化指标（准确率/成本/延迟，前后对比）
5. **复盘**：如果重做会改什么

### Q2. 项目追问清单（面试官必挖的 8 个方向）
- 数据从哪来？量级多大？怎么清洗标注？
- 为什么用 X 不用 Y？（每个技术选型都要能答出对比）
- 遇到什么 badcase？怎么定位到根因的？
- 效果如何度量？评测集怎么构建的？
- 上线后遇到什么线上问题？怎么解决的？
- 成本多少？还能怎么降？
- 你在团队中的具体贡献？（区分"我做的"和"团队做的"）
- 如果现在重做，你会怎么改进？

### Q3. 没有工业界项目怎么办？（应届生/转行）
- 用高质量个人项目替代：完整度 > 数量（一个从数据到部署的 RAG 应用胜过一个玩具 demo）
- 复现 + 改进论文/开源项目，讲清楚你改进的部分和验证过程
- 参考 [10-AI应用实战](../10-AI应用实战/README.md) 的五个项目路线

## 二、场景设计题（开放式，考思维框架）

### Q4. 如何设计一个大模型驱动的金融风控系统？
- 要点：高准确率要求（幻觉不可接受）→ LLM 只做辅助分析（报告生成、案例检索），决策仍由规则/传统模型出
- 数据合规、可解释性要求、人工复核链路

### Q5. 如何为电商设计智能导购 Agent？
- 意图识别（闲聊/找品/比价/售后）→ 路由
- 商品库检索（结构化查询为主，向量为辅）、多轮澄清需求
- 工具：库存/价格/物流查询 API；护栏：不承诺无依据的折扣

### Q6. 如何衡量"AI 生成的代码"质量？
- 通过率（单测）、静态扫描、人工 review 覆盖率
- 生产指标：AI 生成代码的缺陷率 vs 人工、回滚率
- 流程：Spec → 生成 → 自动验证 → 人工审查 → 灰度

### Q7. 用户反馈"AI 回答质量不稳定"，你怎么排查？
1. 定义"质量"并量化（建评测集）
2. 分链路归因：检索差了？prompt 被改过？模型版本变了？输入分布变了？
3. 加监控埋点定位波动时段/场景
4. 修复 + 加回归测试防复发

### Q8. 老板要求"把大模型接入现有业务"，你的第一步是什么？
- 不是写代码，而是：**找高频、容错、可验证的场景**做试点
- 先 Prompt 验证可行性（一周）→ 量化效果说服投入 → 再工程化
- 反例：一上来买卡训模型，三个月后发现场景不成立

### Q9. 长上下文、RAG、微调，三个技术路线怎么选？（经典权衡题）
- 动态知识、需溯源 → RAG；固定行为模式/格式 → 微调；一次性分析超长文档 → 长上下文
- 成本对比 + 组合使用（三者不互斥）

### Q10. 如何看待 Agent 的现状与泡沫？（认知题）
- 现状：编程/研究类 Agent 已产生真实价值（垂直、闭环、可验证场景）
- 局限：通用自主 Agent 仍受限于可靠性（错误累积）、成本、评估难
- 答题公式：**承认价值 + 说清边界 + 给出你的一线观察**

## 三、行为面与软技能

### Q11. 自我介绍模板（1 分钟版）
```
我是谁（背景一句话）→ 与岗位最相关的 2 个经历（各一句量化结果）
→ 为什么投这个岗位（匹配点）→ 结尾引到项目（"我可以详细展开 XX 项目"）
```

### Q12. 你的优势和不足？
- 优势：绑定岗位需求 + 举例证明
- 不足：真实的、非致命的、且已在做改进（附改进行动与进展）

### Q13. 遇到意见分歧/项目失败怎么办？
- 用真实故事，结构：分歧点 → 我的主张与依据 → 如何验证（数据/小实验）→ 结果与学到什么
- 避免：把责任全推给别人、说"从没失败过"

### Q14. 如何保持对 AI 领域的学习？
- 具体信息源（论文渠道/博客/社区，见 [11-学习资源导航](../11-学习资源导航/README.md)）
- 学习方式：复现 > 阅读；输出 > 输入（写笔记/做分享/做项目）
- 准备一个"最近让你兴奋的技术"话题并能讲 3 分钟

### Q15. 反问环节问什么？（最后加分项）
- 团队当前最主要的技术挑战是什么？
- 这个岗位前 3 个月最重要的交付是什么？
- 团队的模型/技术栈选型是怎么决策的？
- 避免问：能轻易搜到的信息、只关心福利加班（可留到 HR 面）

## 四、编码/算法环节（AI 岗也常考）

- **常规算法**：LeetCode 热题 100（数组/链表/树/DP），AI 岗笔试不减配
- **ML 手撕题**：手写 K-Means、LR 梯度下降、自注意力、Top-p 采样
- **工程题**：实现一个带 LRU 缓存的推理服务接口、多线程 batch 处理
- 建议：重点练"手写 self-attention（含 mask）"和"实现简化版 top-p 采样"，出现率极高
